# 02. 게임플레이 시스템 설계

## 1. 코어 루프 (Core Loop)
1. 탐험 → 2. 전투/퀘스트 → 3. 보상(경험치/아이템/골드) → 4. 성장(레벨업/장비/스킬) → 5. 더 위험한 지역 탐험

---

## 2. 전투 시스템

### 2.1 전투 방식 (선택지)
- **A. 액션 기반**: 실시간 전투, 회피/콤보 등 조작 요구
- **B. 턴제/세미리얼**: ATB(Active Time Battle) 또는 전통적 턴제
- **C. 하이브리드**: 필드 액션 + 보스전 턴제

> **추천**: 초안으로는 **B(세미리얼 ATB)** 또는 **A(액션)** 중 프로토타입으로 검증. 인디 개발 난이도 고려 시 A가 더 구현 복잡, B가 데이터 주도로 관리 용이.

### 2.2 전투 구성요소
- **플레이어 스탯**: HP, MP(마나), 공격력, 방어력, 민첩성, 크리티컬, 저항 등
- **적 스탯**: 동일 + AI 패턴
- **스킬 시스템**: 액티브/패시브 스킬, 쿨타임/MP 소모
- **상태이상**: 중독, 빙결, 화상, 감속 등
- **속성 상성**: 화염/물/바람/대지/암흑/신성 등 (무속성 포함)
- **크리티컬/회피**: 확률 기반 + 장비 보정

### 2.3 적 AI
- 일반 몹: 단순 접근-공격 패턴
- 엘리트 몹: 스킬 사용 + 패턴 변화
- 보스: 페이즈(Phase) 기반 다단계 패턴

---

## 3. 성장 시스템

### 3.1 레벨 시스템
- 경험치 획득 → 레벨업 → 스탯 포인트/스킬 포인트 지급
- 레벨 상한: 50 (가정)
- 레벨업 시 HP/MP 자동 증가 + 포인트로 스탯 수동 분배

### 3.2 직업/클래스
- 게임 시작 시 또는 초반에 선택: **전사, 마법사, 궁수, 도적** 등
- 클래스별 고유 스킬 트리 + 장비 제한(무기/방어구)
- 종족 × 클래스 조합 (예: 오크 전사, 엘프 마법사)

### 3.3 스킬 시스템
- 스킬 포인트로 습득/레벨업
- 스킬 트리 구조: 공통 → 클래스 → 고급 → 궁극
- 스킬 예시:
  - 전사: 파워 슬래시, 방어 태세, 분노
  - 마법사: 파이어볼, 아이스 랜스, 메테오
  - 궁수: 연사, 관통 화살, 치명 조준
  - 도적: 암습, 독 칼날, 그림자 걸음

### 3.4 장비 시스템
- 슬롯: 무기, 방패/보조, 투구, 갑옷, 장갑, 부츠, 반지, 목걸이 등
- 등급: 일반(Common) → 고급(Uncommon) → 희귀(Rare) → 영웅(Heroic) → 전설(Legendary) → 신화(Mythic)
- 옵션: 기본 스탯 + 세트 효과 + 랜덤 옵션
- 강화 시스템: 골드/재료로 강화 (+1 ~ +10), 실패 시 하락 또는 파괴(설정 가능)

---

## 4. 퀘스트 시스템

### 4.1 퀘스트 종류
| 종류 | 설명 | 보상 |
|------|------|------|
| 메인 퀘스트 | 스토리 진행 | 경험치, 스토리 진행, 장비 |
| 사이드 퀘스트 | NPC 요청, 탐험 | 경험치, 골드, 아이템 |
| 일일/주간 퀘스트 | 반복 콘텐츠 | 골드, 재료 |
| 종족 퀘스트 | 종족 전용 스토리 | 종족 아이템, 평판 |
| 탐험 퀘스트 | 특정 지역 발견/클리어 | 지도, 업적 |

### 4.2 퀘스트 데이터 구조
```yaml
quest:
  id: "main_001"
  name: "세계수의 균열"
  type: "main"          # main / side / daily / race
  description: "..."
  prerequisites: ["intro_001"]
  objectives:
    - type: "kill"      # kill / collect / talk / reach / escort
      target: "goblin"
      count: 5
    - type: "reach"
      location: "elder_tree"
  rewards:
    exp: 500
    gold: 100
    items: ["sword_iron"]
  next_quest: "main_002"
```

### 4.3 다이얼로그 시스템
- NPC별 대화 트리, 조건 분기(레벨/퀘스트 진행도/종족/평판)
- 선택지에 따라 평판/퀘스트 분기
- 대사 데이터는 스프레드시트/JSON으로 관리

## 5. 제작/경제 시스템

### 5.1 제작
- 재료 수집(채집/몬스터 드롭/채굴) → 레시피로 아이템 제작
- 제작 숙련도: 성공 시 추가 아이템/경험치
- 제작 NPC(대장장이, 연금술사 등)에 의뢰 가능

### 5.2 경제
- 통화: 골드(기본) + (선택) 귀금속/토큰
- 상점: 일반 상점, 플레이어 상점(플레이어 간 거래 - 온라인 시)
- 경매/거래 시스템 (온라인 연동 시)
- 물가: 지역/세력별 차등 (전쟁 지역 등)

### 5.3 인벤토리
- 무게/슬롯 기반 (선택) 또는 무제한 + 정렬/필터
- 창고/가방 확장
- 퀵슬롯(소비 아이템/스킬)

---

## 6. 탐험/오픈월드 시스템

### 6.1 맵/이동
- 연속형 오픈월드 (로딩 화면 최소화) 또는 존 단위 로딩
- 이동 수단: 도보, 탈것(후반), 순간이동(마법/비석), 지도 빠른 이동
- 날씨/시간 시스템: 낮/밤, 비/눈 등 (시각적 + 일부 퀘스트 조건)

### 6.2 발견 요소
- 미니맵/FoW(Fog of War) 해제
- 숨겨진 보물 상자, 동굴, 유적
- 수집 요소(전설의 파편 등)
- 랜덤 인카운터/동적 이벤트(이동 중 몬스터 습격 등)

### 6.3 동적 시스템
- 몬스터 리스폰/순회
- 이벤트 퀘스트(조건 충족 시 발생)
- 날씨/시간에 따른 NPC 스케줄

---

## 7. 소셜/멀티플레이 (향후)

- 파티/길드 시스템
- 플레이어 간 거래/경매
- PvP(선택적, 특정 지역/이벤트)
- 채팅/귓속말

> 싱글플레이 우선 개발 후 온라인 기능 단계적 추가 권장.

---

## 8. 저장/진행

- 자동 저장 + 수동 저장(허브에서)
- 세이브 슬롯 다중 지원
- 클라우드 세이브(온라인 연동 시)

---

## 9. 밸런싱 원칙

- **경험치 곡선**: 레벨업에 필요한 경험치는 지수적 증가
- **몬스터 스탯**: 존 레벨대에 맞춰 스케일링, 일반/엘리트/보스 비율 70/25/5
- **드롭률**: 희귀 아이템은 낮은 확률, 반복 파밍 가능
- **경제**: 인플레이션 방지용 싱크(강화 비용, 수리비 등)
- **난이도**: 3단계(쉬움/보통/어려움) 선택 가능
